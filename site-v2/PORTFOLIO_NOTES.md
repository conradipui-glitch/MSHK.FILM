# MSHK.FILM — визуальный кандидат (v2)

Исходник: пользовательский ZIP `mshkfilm-portfolio-website-design.zip`. Исходные файлы в `site/`, готовый HTML собирается GitHub Actions.

Изменения: фирменный знак и портрет Михаила из загруженных исходников, безопасная подача роли в SEBERO, менее категоричные обещания, корректный сценарий копирования заявки. Сохранён визуальный язык REC / AF / таймкод / хлопушка.

## Нужна проверка перед релизом
- Подтвердить роли в каждой работе и ссылки на проекты Миши Шульца.
- Подтвердить условия услуг и состав выдаваемых материалов.
- Проверить в Chrome мобильный и десктопный вид, modal/Telegram embed, копирование, доступность.
- Стоковые Pexels-фотографии пока обозначены как иллюстрации, заменить на реальные кадры при получении исходников.
- Сайт собирается во внешней GitHub Actions, если сборка в рабочей среде недоступна.
