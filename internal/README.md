# Кабинет видеографа — внутренние материалы

`MSHK_FILM_Field_Cabinet.html` — автономный HTML с учебными материалами, расчётом смет, скриптами переписки, упражнениями и таблицей потенциальных клиентов.

**Не входит в GitHub Pages:** сайт раздаётся только из `docs/`.

**Важная оговорка:** репозиторий открыт всему интернету; исходники этой папки публичны на GitHub. Рабочие списки клиентов, реальные переговоры, цены конкретных сделок и личные данные необходимо хранить в частной локальной копии. Пустой кабинет сохраняет данные в браузере локально и не отправляет их в GitHub.

Исследование и развитие кабинета — отдельно от публичного сайта.
