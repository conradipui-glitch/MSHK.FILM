# MSHK.FILM — Михаил Мушкачев

Сайт-портфолио видеографа и внутренние материалы для развития самостоятельной практики.

## Структура
- `docs/` — **единственный публичный сайт**, рассчитан на GitHub Pages (Source: Deploy from a branch → main → /docs).
- `internal/` — интерактивный кабинет видеографа и шаблоны. **Не публикуется на GitHub Pages**, но исходники доступны в публичном GitHub.
- `research/` — рабочие исследования и план YAAI; не публикуются на Pages.

## Публикация сайта
В GitHub откройте **Settings → Pages → Build and deployment** → **Deploy from a branch**, Branch **main**, Folder **/docs**, затем Save.

Ожидаемый тестовый адрес после активации Pages:
https://conradipui-glitch.github.io/MSHK.FILM/

До проверки настроек не считайте Pages опубликованным.

## Состояние
Первый интерактивный сайт с временными фотоматериалами (не выдаются за работы Михаила); ссылки портфолио ведут на его настоящие публикации в Telegram. Не публиковать цены, сроки, отзывы или неутверждённые обещания от имени автора.

Контакты: [Telegram-канал](https://t.me/mushkachev), [связь с Михаилом](https://t.me/mmushkachev).


## Новый дизайн — film-v2 (предпросмотр)
- `site-v2/` — исходники альтернативного кинематографического варианта из присланного ZIP (React + Vite + Tailwind).
- `.github/workflows/build-film-v2-preview.yml` — проверенная автоматическая сборка в `docs/v2/` при изменениях `site-v2/**`.
- [Посмотреть новый вариант](https://conradipui-glitch.github.io/MSHK.FILM/v2/) — **предпросмотр**, не заменяет главную страницу.
- Оригинальные логотип и портрет размещены в `site-v2/public/assets/`, без дополнительной генерации.
- `site-v2/PORTFOLIO_NOTES.md` — ограничения и проверки перед переключением главной версии.

Главная страница в `docs/index.html` пока остаётся прежней. Для переноса film-v2 в корень Pages потребуется отдельное решение и изменение сборочного назначения.
